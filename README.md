# Personalized Application Writer

Tailor an application to the real evidence in your experience while preserving a natural, truthful voice.

**Author:** Edward Xiong  
**Format:** Portable Agent Skill (`SKILL.md`)  
**Updated:** October 6, 2026

## Use it

Copy `SKILL.md` into an agent skill directory supported by your tool, or paste the starter prompt into a chat model and replace the bracketed inputs. The instructions are model-agnostic.

## What it does

You are applying for an opportunity and need relevant, specific writing.

## Workflow

1. Read the prompt and selection criteria closely.
2. Build an evidence map from supplied experience.
3. Draft around concrete choices and outcomes.
4. Check every claim and keep the applicant’s voice.
